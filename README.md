🛠️ Step-by-Step Setup Guide / ধাপে ধাপে সেটআপ নির্দেশিকা

1. Prerequisites / প্রাথমিক প্রস্তুতি

IDE: Download and install Google AntiGravity or VS Code.

Account: You must have a GitHub account.

IDE: আপনার পিসিতে Google AntiGravity বা VS Code ইনস্টল থাকতে হবে।

অ্যাকাউন্ট: আপনার একটি সচল GitHub অ্যাকাউন্ট থাকতে হবে।

2. Agent Ruter Configuration / এজেন্ট রুটার কনফিগারেশন

This platform provides the free API keys for the AI models.
এই প্ল্যাটফর্মটি আপনাকে এআই মডেল ব্যবহারের জন্য ফ্রি এপিআই কি (API Key) প্রদান করবে।

Go to Agent Ruter and click "Sign Up with GitHub".

Upon signup, check your Wallet; you will see a $100 bonus.

Pro Tip: Log in daily to receive a $25 daily credit.

Navigate to Console > API Token.

Click "Create Token", give it a name (e.g., MyFreeAI), and set the expiration to 2070.

Crucial: Enable the "Unlimited Quota" toggle.

Click Submit and copy the generated API Key.

১. Agent Ruter ওয়েবসাইটটিতে যান এবং "Sign Up with GitHub" বাটনে ক্লিক করুন।
২. সাইন-আপ করার পর আপনার Wallet চেক করুন; আপনি $100 বোনাস দেখতে পাবেন।
৩. প্রো টিপ: প্রতিদিন অন্তত একবার লগইন করলে আপনি $25 ডেইলি ক্রেডিট পাবেন।
৪. মেনু থেকে Console > API Token-এ যান।
৫. "Create Token" এ ক্লিক করে একটি নাম দিন এবং মেয়াদ ২০৭০ সাল পর্যন্ত সেট করুন।
৬. অবশ্যই: "Unlimited Quota" অপশনটি অন (Enable) করে দিন।
৭. Submit এ ক্লিক করুন এবং তৈরি হওয়া API Key-টি কপি করে নিরাপদ কোথাও রাখুন।

3. Install Roo Code Extension / রু কোড এক্সটেনশন ইনস্টল

Open Google AntiGravity/VS Code.

Go to the Extensions marketplace (Ctrl+Shift+X).

Search for "Roo Code" and install the one with 1.4M+ downloads.

১. Google AntiGravity বা VS Code ওপেন করুন।
২. Extensions আইকনে ক্লিক করুন (বা Ctrl+Shift+X চাপুন)।
৩. সার্চ বক্সে "Roo Code" লিখে ১.৪ মিলিয়ন ডাউনলোডের অফিসিয়াল এক্সটেনশনটি ইনস্টল করুন।

5. Advanced Technical Settings / উন্নত টেকনিক্যাল সেটিংস

To ensure a smooth experience, apply these settings in Roo Code:
নিরবচ্ছিন্ন কাজের অভিজ্ঞতার জন্য রু কোড-এ নিচের সেটিংসগুলো প্রয়োগ করুন:

Auto-Approve: Enable Read and Auto-approve to stop the AI from asking permission for every small step. (AI যাতে বারবার অনুমতি না চায় সেজন্য এটি অন করুন।)

MCP Mode: Enable Read-write MCP mode.

Custom Instructions: Paste the following in the instructions field: "No browse rule. Focus on clean, modular code and follow best practices." (এটি এআই-কে অপ্রয়োজনীয় ব্রাউজিং থেকে বিরত রাখবে এবং কোড দ্রুত লিখবে।)

Disable Questions: Turn off the "Question option" to reduce interruptions.

Use DeepSeek R1 for complex logic, algorithms, and deep architectural problems. (জটিল লজিক বা গাণিতিক সমস্যার জন্য R1 ব্যবহার করুন।)
